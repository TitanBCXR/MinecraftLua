# Media

## `tetris_lofi.dfpwm`

Original ~48s lo-fi loop for the Tetris pocket game.

- **License:** CC0 / public domain (generated for this repo — not the Tetris theme)
- **Format:** DFPWM1a @ 48 kHz (CC: Tweaked speaker)
- **Regenerate:** `python scripts/gen_tetris_lofi.py`

Pockets download it over HTTP on boot:

`https://raw.githubusercontent.com/TitanBCXR/MinecraftLua/main/media/tetris_lofi.dfpwm`
